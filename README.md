# פורמולה תשתיות — אתר הקבוצה

אתר תאגידי לקבוצת פורמולה תשתיות: שמונה חברות בשלושה תחומי פעילות, המכסות יחד
את מחזור החיים המלא של פרויקט תשתית.

Next.js (App Router) · TypeScript · Tailwind CSS v4 · Three.js · עברית RTL.

## הפעלה

```bash
npm install
npm run dev            # פיתוח, http://localhost:3000
npm run build && npm run start   # בנייה והרצה כמו בייצור
npm run lint
npm run smoke          # בדיקת עשן בדפדפן אמיתי על כל העמודים
```

בדיקת העשן טוענת כל עמוד ב־Chromium ונכשלת על כל דבר שגולש היה מבחין בו:
סטטוס שאינו 200, שגיאת קונסולה (כולל סקריפט שנחסם על ידי ה־CSP), עמוד שלא
עבר הידרציה, או גלישה אופקית. יש להריץ אותה מול שרת חי.

## מבנה

| נתיב | תיאור |
| --- | --- |
| `src/data/site.ts` | **כל התוכן** — חברות, תחומי פעילות, פרויקטים, מסלול הפרויקט, ניווט |
| `src/app/` | העמודים (App Router) |
| `src/components/Hero3D.tsx` | סצנת ה־WebGL של עמוד הבית |
| `src/components/LifecyclePath.tsx` | מסלול הפרויקט המונפש בגלילה |
| `src/middleware.ts` | Content-Security-Policy עם nonce לכל בקשה |
| `next.config.ts` | שאר כותרות האבטחה |
| `docs/spec.html` | מסמך האפיון שממנו נבנה האתר |

עדכון תוכן נעשה כמעט תמיד ב־`src/data/site.ts` בלבד.

## הסצנה התלת־ממדית

ענן נקודות בסגנון סריקת LiDAR שמתגבש למבנה בנוי עם מסדרון תשתית חוצה. זה
מייצג את מסלול הקבוצה: מידע גולמי ← תכנון ← ביצוע.

- נטענת רק בעמוד הבית, ורק אחרי שהעמוד מוכן (`import("three")` דינמי).
- נעצרת כשהיא מחוץ למסך או כשהלשונית ברקע.
- במסכים קטנים: פחות נקודות ו־pixel ratio נמוך יותר.
- כשהמשתמש הגדיר `prefers-reduced-motion` — לא נטענת כלל, ובמקומה רשת סטטית.

## אבטחה

- **CSP עם nonce לכל בקשה** (`src/middleware.ts`), בלי `unsafe-inline` ל־script.
  זו הסיבה ש־`src/app/layout.tsx` קורא ל־`headers()`: הקריאה מוציאה את העמודים
  מרינדור סטטי, וזה מה שמאפשר ל־Next להטביע את ה־nonce בסקריפטים שלו. בלי זה
  האתר נטען אבל לא עובר הידרציה.
- `Strict-Transport-Security`, `X-Frame-Options: DENY`, `X-Content-Type-Options`,
  `Referrer-Policy`, `Permissions-Policy`, `Cross-Origin-Opener-Policy`.
- טופס יצירת הקשר (`src/app/api/contact/route.ts`): ולידציה בצד שרת, הגבלת קצב
  (5 פניות ל־10 דקות לכל כתובת), ושדה honeypot. תוכן הפנייה אינו נכתב ללוגים.

## פרטיות — תיקון 13

- יידוע בנקודת האיסוף מוצג ליד הטופס עצמו, לא רק בקישור.
- תיבת הסכמה שאינה מסומנת מראש, ונאכפת גם בצד השרת.
- מסירת המידע לחברת הקבוצה הרלוונטית מוצהרת במפורש — הקבוצה בנויה מישויות
  משפטיות נפרדות, וזו נקודה שקל לפספס.
- `src/app/legal/privacy` ו־`legal/accessibility` הם **טיוטות** המסומנות ככאלה
  באתר, וטעונות אישור היועץ המשפטי לפני ההשקה.

## נגישות

נבנה לפי ת״י 5568 / WCAG 2.0 AA: מבנה כותרות סמנטי, ניווט מלא במקלדת, קישור
דילוג לתוכן, סימון פוקוס, תוויות לכל שדה, וכיבוד `prefers-reduced-motion`
בכל האנימציות ובסצנה התלת־ממדית.
